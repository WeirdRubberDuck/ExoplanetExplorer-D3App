# ExoplanetExplorer-WebbApp
A web application accompanying the research exoplanet explorer tool in OpenSpace (https://github.com/OpenSpace/OpenSpace).

The web app is located in the [exoplanet-explorer](https://github.com/WeirdRubberDuck/ExoplanetExplorer-WebApp/tree/main/exoplanet-explorer) folder. 

The `old-page` is an archived version of the webpage, before it was implemented in React, kept for historical reasons and ot be able to reimplement features if necessary. 

## Built on OpenSpace
The webpage requires a [specific branch in OpenSpace](https://github.com/OpenSpace/OpenSpace/tree/project/exoplanet-explorer-gaia).
