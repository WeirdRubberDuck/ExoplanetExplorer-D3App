# Interaction and Navigation


## Camera Controls

Use the standard [OpenSpace navigation controls](https://docs.openspaceproject.com/releases-v0.22/getting-started/navigation/index.html) to move the camera around the scene.


## Object Glyphs

| Instruction |  |
| --- | --- |
| Hold **Ctrl** and **hover** over an object glyph to show its name. | <img src={hoverGif} alt="Hover over object glyph" width="250" /> |
| Hold **Ctrl** and **double-click** a glyph to open that system's menu. <br /> <br />This also adds a marker around the selected ring. Hold **Ctrl** and double-click somewhere else on screen (not on another ring) to remove the marker. | <img src={openSystemViewGif} alt="Double-click object glyph" width="700" /> |


## Detailed 3D View

Click **Add System** in the system menu, then focus on the system and fly manually or click **Zoom to Star**. Zoom out to get back to the spatial overview.

You can also use the **Target** button underneath each planet to focus on individual planets.
